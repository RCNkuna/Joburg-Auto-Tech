# Joburg Auto Tech Website
A modern and responsive automotive workshop website built using HTML and CSS.

This project was created as a redesign concept for Joburg Auto Tech, a Johannesburg-based vehicle repair and diagnostics workshop.

## Features
- Modern dark automotive design
- Responsive layout
- Hero section with call-to-action buttons
- Services section
- About section
- Customer reviews
- Contact form
- Formspree booking integration
- Smooth hover effects and animations

## Technologies Used
- HTML5
- CSS3
- Google Fonts
- Formspree
